# Module 7: Infrastructure as Code (IaC) & Terraform

## Overview

This module covers the fundamentals of Infrastructure as Code (IaC) using Terraform.

You'll learn how Terraform works, how it provisions cloud infrastructure, and the concepts required to build and manage infrastructure efficiently.

## Topics

- Why Infrastructure as Code Changed Cloud Engineering
- How Terraform Actually Works (init → plan → apply)
- Terraform State Explained
- Terraform State Locking
- Remote Backend
- Terraform Modules
- Variables, Outputs & Locals
- Terraform Workspaces
- Lifecycle & Dependency Graph
- Terraform Production Best Practices

## Learning Outcome

After completing this module, you'll be able to:

- Understand Infrastructure as Code
- Provision cloud resources using Terraform
- Manage Terraform State
- Build reusable Terraform configurations
- Follow production-ready Terraform best practices
